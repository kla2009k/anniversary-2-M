# ของที่ลืมใส่ในกล่อง · 2 เดือนของเรา

เกมพัสดุ 3D point-and-click สำหรับครบรอบสองเดือน — เปิดกล่องพัสดุไทยธรรมดา แล้วค้นของจริงทีละชั้น 8 รายการ ก่อนพบรูปนักเรียนที่ลืมส่งและเปิดความทรงจำสี่บทกับจดหมายท้ายกล่อง

## เล่น

1. รับพัสดุ → แกะเทป → เปิดฝากล่อง
2. คลิกของชั้นบนก่อน ของชั้นถัดไปจึงปรากฏ; เมื่อเจอครบ 8 ชิ้น จะเปิดรูปนักเรียนซึ่งไม่ได้อยู่ในพัสดุจริง
3. ลากโมเดลเพื่อหมุน กด + / − เพื่อซูม กดปุ่มเฉพาะชิ้นเพื่อเปิด/คลี่/พลิก
4. ตอบคำถาม อ่านความทรงจำก่อนและหลังคบกัน และเปิดการ์ดโน้ต 40 ใบ (3 ใบต่อของจริง 8 ชิ้น + 16 ใบของรูป)
5. ค้นครบแปดชิ้นและเปิดรูปที่ลืมส่งเพื่ออ่านบทสรุป

ความคืบหน้าเก็บไว้ใน browser localStorage; ปุ่ม “เริ่มใหม่” ล้างความคืบหน้าเท่านั้น โมเดลทั้งแปดชิ้นและการ์ดรูปนักเรียนสร้างด้วยเรขาคณิต 3D ใช้พื้นผิวจากภาพอ้างอิงที่ผู้ใช้ส่งมาในบางชิ้น เสียงโฟลีย์สเตอริโอ 48 kHz จำนวน 14 คลิปสังเคราะห์ขึ้นสำหรับโปรเจกต์นี้ให้มีสัมผัสแบบ close-mic/ASMR (ไม่ใช่เสียงบันทึกจริง) ภาพสีน้ำเป็น SVG ต้นฉบับใน `public/art` ไม่มีภาพแชท ที่อยู่ หรือเบอร์โทรศัพท์ รูปนักเรียนที่ผู้ใช้ส่งมาอยู่ในเว็บไซต์โดยครอปออกส่วนป้ายชื่อแล้ว การ์ดที่ระบุ “มุกในเกม” เป็นข้อความแต่ง ไม่ใช่เหตุการณ์จริง

สร้างไฟล์เสียงใหม่ได้ด้วย `python tools/generate_sfx.py` (ใช้ NumPy และ SciPy) และทดสอบการเล่นด้วย `python tools/smoke_test.py` หลังเปิด dev server (ใช้ Playwright กับ Chrome)
