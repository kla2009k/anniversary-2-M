# ของที่ลืมใส่ในกล่อง · 2 เดือนของเรา

เกมพัสดุ 3D point-and-click สำหรับครบรอบสองเดือน — เปิดกล่องพัสดุไทยธรรมดา แล้วค้นของจริงทีละชั้น 8 รายการ ก่อนเปิดความทรงจำสี่บทและจดหมายท้ายกล่อง

## เล่น

1. รับพัสดุ → แกะเทป → เปิดฝากล่อง
2. คลิกของชั้นบนก่อน ของชั้นถัดไปจึงปรากฏ
3. ลากโมเดลเพื่อหมุน กด + / − เพื่อซูม กดปุ่มเฉพาะชิ้นเพื่อเปิด/คลี่/พลิก
4. ตอบคำถาม อ่านความทรงจำก่อนและหลังคบกัน
5. ค้นครบแปดชิ้นเพื่อเปิดบทสรุป

ความคืบหน้าเก็บไว้ใน browser localStorage; ปุ่ม “เริ่มใหม่” ล้างความคืบหน้าเท่านั้น โมเดลทั้งแปดชิ้นสร้างด้วยเรขาคณิต 3D และใช้พื้นผิวจากภาพอ้างอิงที่ผู้ใช้ส่งมาในบางชิ้น เสียงโฟลีย์สเตอริโอ 48 kHz จำนวน 14 คลิปสังเคราะห์ขึ้นสำหรับโปรเจกต์นี้ให้มีสัมผัสแบบ close-mic/ASMR (ไม่ใช่เสียงบันทึกจริง) ภาพสีน้ำเป็น SVG ต้นฉบับใน `public/art` ไม่มีภาพแชท ที่อยู่ เบอร์โทรศัพท์ หรือภาพบุคคลในเว็บไซต์

สร้างไฟล์เสียงใหม่ได้ด้วย `python tools/generate_sfx.py` (ใช้ NumPy และ SciPy) และทดสอบการเล่นด้วย `python tools/smoke_test.py` หลังเปิด dev server (ใช้ Playwright กับ Chrome)

## พัฒนา

```bash
npm ci
npm run dev
npm run build
npm run preview
```
