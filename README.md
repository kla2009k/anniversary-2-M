# ของที่ลืมใส่ในกล่อง · 2 เดือนของเรา

เกมพัสดุ 3D point-and-click สำหรับครบรอบสองเดือน — คัตซีนคัตเตอร์กรีดเทป เปิดกล่องพัสดุไทยธรรมดา แล้วค้นของจริงทีละชั้น 8 รายการ ก่อนพบรูปนักเรียนที่ลืมส่ง กล่องมุกสมมติ 5 ชิ้น และความทรงจำสี่บทกับจดหมายท้ายกล่อง

## เล่น

1. รับพัสดุ → ดูคัตซีนคัตเตอร์กรีดเทป → ดูฝากล่องค่อย ๆ เปิด
2. คลิกของชั้นบนก่อน ของชั้นถัดไปจึงปรากฏ; เมื่อเจอครบ 8 ชิ้น จะเปิดรูปนักเรียนซึ่งไม่ได้อยู่ในพัสดุจริง
3. ลากโมเดลเพื่อหมุน กด + / − เพื่อซูม กดปุ่มเฉพาะชิ้นเพื่อเปิด/คลี่/พลิก
4. ตอบคำถาม อ่านความทรงจำก่อนและหลังคบกัน และเปิดการ์ดโน้ต 60 ใบ (3 ใบต่อของจริง 8 ชิ้น + 16 ใบของรูป + 4 ใบต่อของสมมติ 5 ชิ้น)
5. ค้นครบแปดชิ้นและเปิดรูปที่ลืมส่งเพื่ออ่านบทสรุป; หรือเปิดกล่องมุก 5 ชิ้นเพิ่มเติมก็ได้โดยไม่บังคับ

ความคืบหน้าเก็บไว้ใน browser localStorage; ปุ่ม “เริ่มใหม่” ล้างความคืบหน้าเท่านั้น โมเดลของจริงทั้งแปดชิ้น การ์ดรูปนักเรียน และไอเทมสมมติห้าชิ้นสร้างด้วยเรขาคณิต 3D ใช้พื้นผิวจากภาพอ้างอิงที่ผู้ใช้ส่งมาในบางชิ้น ภาพสีน้ำเป็น SVG ต้นฉบับใน `public/art` ไม่มีภาพแชท ที่อยู่ หรือเบอร์โทรศัพท์ รูปนักเรียนที่ผู้ใช้ส่งมาอยู่ในเว็บไซต์โดยครอปออกส่วนป้ายชื่อแล้ว การ์ดที่ระบุ “มุกในเกม” เป็นข้อความแต่ง ไม่ใช่เหตุการณ์จริง

เสียงตอนนี้เป็นคลิปสั้นที่ตัดจาก **การบันทึกเสียงจริง** แบบ CC0 ของ Freesound ไม่ใช่เสียงสังเคราะห์ คลิปที่ใช้มีแปดชนิด: [ลอกเทป 405586](https://freesound.org/s/405586/), [เปิดกล่องกระดาษ 235807](https://freesound.org/s/235807/), [พลิกกระดาษ 353125](https://freesound.org/s/353125/), [ขยับห่อพลาสติก 536288](https://freesound.org/s/536288/), [ถุงกระดาษ 377634](https://freesound.org/s/377634/), [เปิดภาชนะพลาสติก 641210](https://freesound.org/s/641210/), [ขยับเครื่องประดับ 655872](https://freesound.org/s/655872/), และ [ถุงกระดาษกรอบ 716928](https://freesound.org/s/716928/) ทุกหน้าระบุ Creative Commons 0 ตรงกับไฟล์ที่สคริปต์ตรวจสอบก่อนดาวน์โหลด เสียงบางปุ่มใช้คลิปเดียวกัน เช่นโน้ตกับหนังสือใช้เสียงกระดาษ

สร้างไฟล์เสียงใหม่ได้ด้วย `python tools/fetch_real_foley.py` (ใช้ Requests, NumPy, SciPy และ imageio-ffmpeg) และทดสอบการเล่นด้วย `python tools/smoke_test.py` หลังเปิด dev server (ใช้ Playwright กับ Chrome)

```bash
npm ci
npm run dev
npm run build
npm run preview
```
